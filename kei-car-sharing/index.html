社宅 580あ・・・3

社宅カーシェア

単身赴任の3人で中古の軽自動車を1台持ち、予約と費用を公平に回すための計画書と共有ツールです。予約・走行記録・精算は全員の画面に同じ内容が表示されます。

結論

新任者の名義で中古の軽を買い、2人は月額で「利用料」を払う

先輩2人は近いうちに転勤する可能性があります。3人で出資すると、誰かが抜けるたびに持分の買い取りと精算が発生します。そこで、いちばん長く残る見込みの新任者が所有者・使用者・保険の契約者になり、他の2人は「固定費の頭割り（車の値下がり分を含む）＋走行距離に応じた料金」を毎月払う形をおすすめします。

この形なら、先輩が転勤しても翌月から支払いをやめるだけで済みます。出資していないので、持分の精算はありません。

お金の流れ

毎月の支払いは名義人に集める

月額＝固定費の頭割り＋走行距離×km単価−自分が立て替えた給油代。固定費には任意保険・軽自動車税・車検（自賠責含む）の積立、整備・オイル、冬タイヤと履き替え代、車の値下がり分（購入額−売却見込額を使用予定月数で割った額）を入れます。

使い方

平日は先着、土日祝は「優先予約」で公平に

平日は先着順です。土日祝は1人あたり月1回だけ「優先予約」を使えます。それ以外の土日の予約は「通常予約」で、利用日の3日前までなら他の人の優先予約に押し出されることがあります。

出口

2人になったら継続か売却かを決める

人数が減ると1人あたりの負担が増えます（「費用試算」タブ参照）。転勤の内示が出たら1か月前までに共有し、残る人数で続けるか売却するかを決めます。

始めるまでの手順

  1. 会社・社宅の管理者に、社宅駐車場を3人で1台共用してよいか、マイカー規程に触れないかを確認する。
  2. 3人で「ルール」タブの内容に合意する（特に事故時の負担と転勤時の扱い）。
  3. 車を選び、名義人が購入。任意保険は運転者限定なし・年齢条件は3人の最年少に合わせて契約する。
  4. 「費用試算」タブで固定費を計算し、「設定」タブにメンバーとkm単価を入れる。
  5. このページのURLを2人に共有し、編集者として招待する。予約と記録を開始する。
  6. 3か月後にルールと単価を見直す。

土日祝の取り合いを防ぐ方法の比較

      
「月に何日まで」という上限だけだと、月によっては1人で全部の土日を押さえられてしまいます。そこで次の方法を比べ、1つ目を採用しています。

      

        
方式仕組みよい点気になる点

        
          
優先予約＋押し出し
採用		1人月1回だけ、他の人の通常予約より優先できる。他の土日は通常予約で、直前まで押し出され得る全員が毎月最低1回は確実に土日を取れる。空いていれば何回でも使える通常予約は直前まで確定しない

          
週末ローテーション毎月の土日を順番に割り当てる（第1週A、第2週B…）。担当外の人は担当者が使わない日だけ予約分かりやすく、取り合いが起きない担当日に予定が合わないと無駄になる。5週目の扱いを決める必要

          
月初の抽選・ドラフト前月末に希望日を出し合い、くじ順で1日ずつ選ぶ希望が最も反映される毎月の手間がかかる

          
上限日数のみ（当初案）土日祝は1人月4日まで先着単純早い者勝ちで、全土日を1人が押さえられる

始める前の留意点

      
法令・保険の扱いは契約内容や自治体で変わります。最終的には保険会社・会社の総務・自治体に確認してください。

    

    

      

        会社・社宅
        
まず会社に確認すること

        
    
          
  • 社宅駐車場を「3人で1台」共用してよいか（1戸1台などの決まりがないか）。
    • 
          
  • 車庫の届出に必要な駐車場の使用承諾書を出してもらえるか。
    • 
          
  • マイカー通勤・業務使用の規程。共有車は業務・通勤に使わない前提にするのが安全。
    • 
          
  • 同僚間のお金のやり取りを伴う私的な取り決めについて、上長に一言伝えておくか。
    • 
        

      

      

        保険
        
任意保険の設定がいちばん大事

        
    
          
  • 家族ではない3人が運転するので、運転者限定なし（本人・夫婦限定は使えない）。
    • 
          
  • 年齢条件は3人のうち最年少に合わせる。
    • 
          
  • 等級（ノンフリート等級）は記名被保険者＝名義人に付く。事故で保険を使うと名義人の等級が下がり、翌年以降の保険料が上がる。この増額分を誰が持つか決めておく（ルール18）。
    • 
          
  • 対人・対物は無制限。車両保険は車の価格が低ければ外す判断もあり。
    • 
          
  • 名義人が転勤後にこの車を手放す場合、等級を次の車へ引き継げるよう中断証明書の取得も検討。
    • 
        

      

      

        法律・責任
        
名義人に集まる責任

        
    
          
  • 放置駐車違反金の通知は車検証の使用者（名義人）に届く。運転者が出頭・負担する取り決めと、予約記録による運転者の特定が必要。
    • 
          
  • 飲酒運転をするおそれのある人に車を貸すと、貸した側も処罰対象（車両提供罪）。飲酒予定日の予約禁止を明文化する。
    • 
          
  • 自家用車を「有償で貸す」ことは原則として国の許可が必要（道路運送法）。料金は実費の按分にとどめ、名義人が利益を得る設定にしない。
    • 
          
  • 事故の賠償責任は運転者に加え、所有者（運行供用者）にも及ぶ。保険の補償額を十分にしておく。
    • 
        

      

      

        お金
        
見落としやすい費用

        
    
          
  • 軽自動車税は4月1日時点の所有者に1年分かかる（自家用乗用で年10,800円）。年度途中で売っても月割りで戻らない。
    • 
          
  • 車検（2年ごと）は自賠責・重量税・整備費で6〜10万円程度。月割りで積み立てる。
    • 
          
  • 雪の多い地域ではスタッドレスタイヤ（4本で数万円）と保管場所。
    • 
          
  • 購入時の名義変更・車庫届出の手数料、売却時の手間。
    • 
          
  • 使わない月も固定費は発生する。月2日も使わない人にとってはレンタカーの方が安い。
    • 
        

      

      

        転勤
        
先輩2人が抜ける前提で設計する

        
    
          
  • 3人→2人で1人あたりの固定費は1.5倍、1人では3倍になる。
    • 
          
  • 出資方式だと、抜ける人の持分を「いくらで買い取るか」で揉めやすい。利用料方式なら精算が不要。
    • 
          
  • 後任者が単身なら新メンバーとして誘える。説明用にこのページを使う。
    • 
          
  • 名義人自身が転勤する場合の出口（名義変更か売却）も最初に決めておく。
    • 
        

      

      

        人間関係
        
揉めるのはお金より「使える日」

        
    
          
  • 週末・連休の取り合いが一番の火種。上限ルールと記録で、偏りを数字で見えるようにする。
    • 
          
  • 汚れ・燃料・小さな傷は気づいた時に記録。後から「誰が」を探さない。
    • 
          
  • 職場の上下関係があるので、新任者からは言い出しにくい。ルールを文書にしておくと角が立たない。

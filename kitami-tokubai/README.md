# 北見とくばいナビ（試作版）

北見市内のスーパーとドラッグストア（ツルハ）から、特売がお得で行きやすいお店をおすすめするWebアプリの試作です。
`index.html` 1ファイルで動きます（ビルド不要）。

## できること
- **通勤ルート沿いモード**：自宅・職場（＋経由地3つまで）を地図タップで置くと、ルートからの寄り道距離が小さいお店を優先する
- **自宅のまわりモード**：自宅から半径◯km以内のお店を探す
- **移動手段**：車／自転車／徒歩で、寄り道の許容距離と所要時間の目安が変わる
- **買う物リスト**：入れた品が特売のお店を優先し、品目ごとの最安店も表示する
- **絞り込み**：スーパー／ドラッグストア、営業中のみ、お気に入りのみ
- **地図**：国道39号・北見道路・北見環状線・道道7号・JR石北本線・常呂川・駅・町名を表示。2本指で拡大縮小、1本指で移動、＋／−／全体ボタン、PCではホイールでも拡大縮小
- **お気に入り（★）**：おすすめ順で優先される。設定はブラウザに保存される

## おすすめ順の決め方
`スコア = 特売のお得さ（割引率の合計。買う物リストの品は3倍） + お気に入り加点 − 移動の手間`

- 移動の手間：通勤モードでは「ルートから外れて戻るまでの道のり」、自宅モードでは「自宅からの道のり」
- 道のりは直線距離 × 1.3 で見積もり

## 試作版の制約
- **特売・価格はサンプル**です（日付と店舗から自動生成し、毎日入れ替わる）
- 店名・住所は北見市内の実在店舗。地図上の位置は**住所の町丁目の代表点**（番地までは反映していない）
- **道路と川の線は概略**（OpenStreetMap等に接続できない環境で作ったため、町丁目の座標と道路の経由地情報から描いている）
- 営業時間は目安です

## 本番化に向けた次のステップ
1. 店舗の番地レベルの座標を取得する（国土地理院のジオコーディング、Google Places など）
2. 特売データの入手方法を決める
   - チラシサイト（トクバイ、Shufoo! など）との提携やAPI利用。無断スクレイピングは規約違反のおそれがある
   - 店舗公式チラシ画像をAIで読み取る
   - ユーザー投稿
3. 地図を実際の地図タイル（Leaflet + OpenStreetMap など）にし、道路ベースのルート計算に置き換える
4. 現在地の取得、特売のプッシュ通知

## データの出典
- 町丁目の座標：[Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)（CC BY 4.0、国土交通省 位置参照情報を加工）
- 駅の座標：Wikipedia 各駅の記事
- 店舗住所：ツルハ公式店舗ページ、イオン北海道、Shufoo!、Yahoo!マップ、東武イーストモール公式など
